# 教育部原住民學生概況統計 C 系列長表 schema

**檔案**：`data/processed/moe-c-series-long.csv`
**範圍**：國民中小學（C 系列 6 張表）× 103–114 學年，237,868 列 × 12 欄
**編碼**：UTF-8 帶 BOM（`utf-8-sig`），Excel 直接開不亂碼
**來源**：教育部統計處《原住民學生概況統計》，`https://stats.moe.gov.tw/files/ebook/indigenous/{學年}/{學年}indigenous.xlsx`

建置：`python -m scripts.moe.fetch` 取檔，`python -m scripts.moe.build_long_table` 攤平。第二步不連網。

---

## ⚠️ 讀之前必須知道的一件事

**不要跨 `表號` 加總。** 6 張表是**同一批學生**的 6 種切法，跨表加總會把同一個人算 6 次。

```python
import pandas as pd

df = pd.read_csv("data/processed/moe-c-series-long.csv", dtype={"校碼": "string"})

# ✅ 正確：先篩表號，再彙總
c11 = df[(df["表號"] == "C1-1") & (df["統計別"] == "在學學生")]
print(c11[c11["學年"] == 114].groupby("族籍別")["人數"].sum().sort_values(ascending=False))
# 阿美族 27280、泰雅族 …

# ❌ 錯誤：沒篩表號
print(df[df["學年"] == 114]["人數"].sum())   # 得到數倍於實際的數字
```

`表號` 欄永不為空，就是為了讓這個限制在結構上看得見，而不是只寫在文件裡。

## 欄位

| 欄 | 型別 | 是否必填 | 說明 |
|---|---|---|---|
| `學年` | 整數 | 必填 | 民國學年（`103`–`114`）。與姊妹專案 `moe-indigenous-stats` 一致，不用西元 |
| `表號` | 字串 | 必填 | `C1-1`／`C1-2`／`C2-1`／`C2-2`／`C2-3`／`C2-4` |
| `統計別` | 字串 | 必填 | `在學學生` 或 `上學年度畢業生` |
| `等級別` | 字串 | 視表號 | 見下方「等級別的三套口徑」 |
| `年級` | 字串 | 視表號×統計別 | **絕對學制年級**（`一年級`–`九年級`），非「該等級別內的第 n 年級」 |
| `族籍別` | 字串 | 僅 `C1-1` | 18 個值：16 個族名 ＋ `其他` ＋ `尚未申報族籍` |
| `性別` | 字串 | `C1-1`／`C2-4` | `男`／`女`（`計` 是彙總，已排除） |
| `設立別` | 字串 | 僅 `C2-3` | `國立`／`直轄市立`／`縣市立`／`私立` |
| `學校所在地` | 字串 | 僅 `C1-2` | 縣市。一律用「臺」，已切除原檔的英文尾綴 |
| `校碼` | 字串 | `C2-1`／`C2-2` | **字串型別**，保留前導零與 `E`（`011301`、`173E16`） |
| `學校名稱` | 字串 | `C2-1`／`C2-2` | 校名有重複，需搭配 `校碼` 才能識別 |
| `人數` | 整數 | 必填 | 非負。原檔的 `-` 讀為 0 |

## 各表號的非空維度

| 表號 | 內容 | 在學學生列的非空維度 | 上學年度畢業生列的非空維度 |
|---|---|---|---|
| `C1-1` | 族籍別 × 性別 × 等級別 | 等級別、族籍別、性別 | 同左 |
| `C1-2` | 縣市 × 等級別 | 等級別、學校所在地 | 同左 |
| `C2-1` | 國中校別 × 年級 | 等級別、校碼、學校名稱、年級 | 等級別、校碼、學校名稱（**無年級**） |
| `C2-2` | 國小校別 × 年級 | 等級別、校碼、學校名稱、年級 | 等級別、校碼、學校名稱（**無年級**） |
| `C2-3` | 等級別 × 設立別 × 年級 | 等級別、設立別、年級 | 等級別、設立別（**無年級**） |
| `C2-4` | 等級別 × 性別 × 年級 | 等級別、性別、年級 | 等級別、性別（**無年級**） |

非空維度由「表號 **×** 統計別」共同決定，不是只由表號決定 —— `C2-1`～`C2-4` 的畢業生在原始檔只有單一總數，沒有年級細分。

## 等級別的三套口徑

原始檔的「國中」在不同表裡範圍不同，長表用不同標籤把差別留在資料裡：

| 值 | 含義 | 出現在 |
|---|---|---|
| `國中`／`國小` | 本科，**不含**補校／進修部 | `C1-1`、`C1-2`、`C2-3`、`C2-4` |
| `國中補校`／`國小補校` | 補校／進修部，獨立一項 | 同上 |
| `國中（含進修部）`／`國小（含進修部）` | 本科 ＋ 進修部合計 | `C2-1`、`C2-2` |

**為什麼要三套**：`C2-1` 的校別清單含進修部學校，其總數等於 `C1-1` 的本科＋補校，而不等於 `C1-1` 的「國中」。若三者都叫「國中」，`groupby("等級別")` 會把兩種範圍的數字混成一個假相等。實測 114 學年：

```
C2-1 校別加總 24,536 = C1-1 國中 24,513 + 國中補校 23
C2-2 校別加總 52,058 = C1-1 國小 52,051 + 國小補校 7
```

`tests/test_moe_long_table.py` 釘住這條等式，也反向釘住「只用本科欄對帳必須失敗」。

## 年級是絕對學制年級

原始檔的 `C2-3`／`C2-4` 用「一年級」指**國中一年級**（即七年級），而 `C2-1` 同一批人標「七年級」。長表一律換成絕對年級：

- 國中系列的相對第 n 年級 → 第 n+6 年級
- 國小系列不變

所以 `年級 == "七年級"` 會同時取到 `C2-1` 與 `C2-3`／`C2-4` 的國中一年級。

**不存在的組合不產列。** 國中沒有四年級 —— 原始檔把這種格印成 `-`，長表不會為它產出一列 0。篩 `等級別=="國中" & 年級=="四年級"` 得到空集合，這是刻意的。

## 長表只有明細，沒有彙總

原始檔的總計欄、「計」列、總計組、「臺灣地區」列都**不在**長表裡。它們在建置時用來驗證明細（114 學年零容差相符），驗證通過後即捨棄。

理由：把彙總混進長表，任何忘記過濾的 `groupby().sum()` 都會得到二至三倍的數字。結構上排除比文件警告可靠。

## 已知的上游算術錯誤

103 與 105 學年的原始檔有 26 處「發布的總計 ≠ 明細加總」。**這不影響長表內容**（長表只存明細），但值得知道原始出版品的這幾個數字對不起來：

| 學年 | 位置 | 發布值 | 明細加總 | 判斷 |
|---|---|---|---|---|
| 103 | `C1-2` 新北市畢業生 | 1,827 | 1,828 | 無旁證可判哪個對 |
| 103 | `C2-1` 表級總計列（畢業生） | 8,750 | 8,742 | `C1-1` 國中＋補校 ＝ 8,742，故 8,750 是離群值 |
| 105 | 4 張表的在學總計欄 | 66,892 | 66,896 | 四表明細一致指向 66,896 |

逐筆清單與查證結論在 `scripts/moe/known_issues.py`。該清單被測試反向釘住：上游哪天修好了，測試會失敗提醒清理。

## 範圍界線

- **只有國中小。** 大專與高中職見姊妹專案 [`moe-indigenous-stats`](https://github.com/ss1111119/moe-indigenous-stats)
- **只有 103–114。** 94–102 學年只有 PDF，沒有表格檔
- **沒有衍生指標。** 不含比率、成長率、佔比，只有原始人數
- **沒有跨機關口徑統一。** 教育部的「原住民學生」定義與原民會、SEGIS 是否一致尚未查證，本檔只忠實攤平單一來源
