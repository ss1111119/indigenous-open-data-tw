# 全國原住民人口長表 schema

**檔案**：`data/processed/moi-indigenous-population-long.csv.gz`
**範圍**：全國原住民人口，**103 個月**（民國 107 年 1 月–115 年 7 月）× 372 個鄉鎮市區，2,660,496 列 × 7 欄
**壓縮**：gzip（8.9 MB；未壓縮 151.6 MB，超過 GitHub 單檔上限）
**編碼**：UTF-8 帶 BOM
**來源**：內政部戶政司開放資料 `ODRP018`〈現住原住民人口按性別、身分、原住民族別分〉

建置：`python -m scripts.moi.fetch` 取檔，`python -m scripts.moi.build_long_table` 攤平。第二步不連網。

```python
import pandas as pd

df = pd.read_csv("data/processed/moi-indigenous-population-long.csv.gz")

# 115 年 7 月各族人口，前 5 名
p = df[df["期別"] == 11507]
print(p.groupby("族別")["人數"].sum().sort_values(ascending=False).head())
# 阿美族 238027、排灣族 116004、泰雅族 104052、布農族 66390、太魯閣族 37477

# 全國總人口的時間序列
print(df.groupby("期別")["人數"].sum())
# 10701 為 559,918、11507 為 638,466
```

## ⚠️ 讀之前必須知道的三件事

### 一、`人數` 為 0 的列有兩種讀法，別混

長表有 62.9% 的列是 0。那是**維度交叉的完整表**：每個鄉鎮市區 × 每個族別 × 每個性別都有一列，即使該組合為 0 人。這是刻意的 —— 「這個鄉鎮沒有卡那卡那富族人」與「這筆資料不存在」是不同的陳述。

但**不存在的組合不產列**：`身分別` 為平埔原住民的列只從期別 **11411** 起出現，之前的期別來源根本沒有這些欄位。篩 `期別 < 11411 & 身分別 == "平埔原住民"` 會得到空集合，不是一堆 0。

### 二、11508 起平埔數字會變成非零，那不是人口成長

平埔原住民目前**全期為 0**。《平埔原住民族群身分法》民國 114-10-23 施行，戶政司在 **11411** 開好欄位，但西拉雅族的身分登記尚未反映到資料。

**第一筆非零預計出現在 11508 之後。屆時全國總數上升，不代表原住民人口成長 —— 那是新類別被納入統計。** 要看真實的人口變化，請排除平埔或分開看。

### 三、只到鄉鎮市區，這是刻意的

來源提供**村里**層級，本專案不散布。實測依據：村里層級 7,524 個非零列中有 1,897 列（25%）少於 10 人，而「村里 × 單一族別 × 性別」有 **32,936 格的值是 1 或 2** —— 那個粒度可以反推到具體個人。聚合到鄉鎮市區後，少於 10 人的只剩 2 列（1%）。

村里明細在取檔階段驗證後即捨棄，**沒有留在本機**。要恢復只能重新向戶政司取檔。

## 欄位

| 欄 | 型別 | 說明 |
|---|---|---|
| `期別` | 整數 | 民國年月，如 `11507` 為 115 年 7 月。範圍 10701–11507，共 103 期 |
| `縣市` | 字串 | 22 個。一律用「臺」 |
| `鄉鎮市區` | 字串 | 372 個（跨期有增減，因行政區調整） |
| `身分別` | 字串 | `平地原住民`／`山地原住民`／`平埔原住民` |
| `族別` | 字串 | 27 個中文族名。**不含羅馬字** |
| `性別` | 字串 | `男`／`女` |
| `人數` | 整數 | 非負，永不為空 |

**每一欄在每一列都非空** —— 這個來源的每個維度都適用於每一列，沒有「不適用」的情況。

## 三個身分別的法源不同

| 值 | 法源 | 取得要件 |
|---|---|---|
| `山地原住民` | 原住民身分法 §2 | 光復前原籍在山地行政區域 ＋ 戶口調查簿登記。**不需申請** |
| `平地原住民` | 原住民身分法 §2 | 同上但原籍在平地行政區域，**且須向鄉鎮市區公所申請登記有案** |
| `平埔原住民` | **平埔原住民族群身分法**（114-10-23 施行） | 依該法登記；§15 要求取用傳統名字／並列／從姓 |

⚠️ **平埔原住民在法律上是另立的類別，不是山地／平地的子類。** 該法 §3 明確把它界定為「既存於臺灣同屬南島語系民族之**其他**臺灣原住民族」，區別於憲法增修條文所稱的山地與平地原住民。

⚠️ **平地原住民的人數取決於有沒有人去申請。** 山地不需申請、平地需要。所以「平地原住民」少於「符合平地原住民條件的人」，差額無從得知。這是制度設計，不是統計誤差。

## 族別清單按身分別而異

| 身分別 | 族別數 |
|---|---|
| 平地原住民 | 17（16 族 ＋ 尚未申報） |
| 山地原住民 | 17（同上） |
| 平埔原住民 | 12（11 族 ＋ 尚未申報） |
| **聯集** | **27** |

平埔獨有 10 族：西拉雅族、大武壠族、馬卡道族、凱達格蘭族、巴布薩族、洪雅族、拍瀑拉族、巴宰族、噶哈巫族、道卡斯族。噶瑪蘭族與尚未申報兩邊都有。

**所以「原住民共 27 族」與「共 17 族」都可能是對的，取決於問的是哪個身分別。**

## 族名跨期收斂為中文

來源在期別 11411 把三個族名的羅馬字改為族語自稱。長表一律存中文，兩種拼法收斂為同一值：

| 中文 | 11410 及之前 | 11411 及之後 |
|---|---|---|
| 鄒族 | `tsou` | `cou` |
| 卑南族 | `puyuma` | `pinuyumayan` |
| 拉阿魯哇族 | `hlaaluaavu` | `hlaalua` |

另有一期（**11308**）來源的欄名全是中文（`原住民_阿美族_男_人數`），也已正規化。三種命名方案的處理寫在 `scripts/moi/registry.py`。

## 長表只有明細，沒有彙總

來源提供的總計欄與身分別小計**不在**長表裡。它們在取檔時用來驗證明細（七組恆等式、全 103 期逐列零容差通過），驗證通過後即捨棄。

理由：把彙總混進長表，任何忘記過濾的 `groupby().sum()` 都會得到數倍的數字。要總計請自己加總，那樣才不會重複計算。

每期的驗證紀錄在 `data/raw/moi/manifest.jsonl`（期別、列數、頁數、鄉鎮市區數、七組恆等式各檢查幾次、欄名版本、取檔時間）。村里明細已捨棄，這份紀錄是唯一的查核依據。

## 範圍界線

- **只有 `ODRP018`。** 戶政司另有 8 個原住民主題資料集（婚姻狀況、教育程度、戶數、平均餘命等），尚未處理
- **只到 11507。** 11508 實測回「查無資料」，發布滯後約兩個月
- **沒有衍生指標。** 不含比率、成長率、佔比
- **不可與教育部長表直接相除。** 兩者的母體定義是否一致尚未查證。姊妹專案 `moe-indigenous-stats` 曾因分子分母口徑不對稱而算出與事實相反的結論，整個指標作廢 —— 要交叉使用請先查證兩份資料的認定基礎
