2026-08-11 於 [[moe-indigenous-stats]] 查證。**教育部的教育統計不是只有 opendata。**

## 一、兩條路徑，不要混

| 路徑 | 內容 | 特性 |
| --- | --- | --- |
| `stats.moe.gov.tw/files/opendata/<檔名>.<json\|csv>` | 開放資料 | 格式穩定、跨年合併在同一個檔（如 `edu_A_1_7` 含 104–114） |
| `stats.moe.gov.tw/files/detail/<學年>/<學年>_<檔名>.<csv\|xls\|xlsx\|ods>` | **明細統計表** | **每學年一個檔**、格式逐年會變 |

opendata 找不到的東西，先去 detail 找。大專的科系別、高中職的學程別、
國中小校別，全都在 detail。

## 二、怎麼找檔名（唯一可行的方法）

**不要用 data.gov.tw 搜尋**：搜尋頁是前端渲染，`?qs=` 參數不會觸發查詢；
實際操作搜尋框送出會回傳與關鍵字無關的結果；`/api/front/dataset/search` 與
`/api/v1/rest/datastore/search` 皆 404，v2 API 只能用**已知 dataset id** 取詮釋資料。
猜檔名也沒用（試過 6 種全 404）。

**正解**：教育部統計處「學校基本統計資訊」頁，**每個學年一頁**，網址形如
`https://depart.moe.edu.tw/ed4500/News_Content.aspx?n=5A930C32CC6C3818&sms=91B3AAE8C6388B96&s=<每年不同>`。
該頁含該學年**全部檔案連結與中文標題**。用 curl 抓下來，
對每個 `href` 往前 1200 字元抓最近的中文標題，就得到「檔名 ↔ 標題」對照。

## 三、已知檔名對照（114 學年）

**校別資料**：`student` 大專校院校別學生數／`teacher` 專任教師／`graduate` 畢業生／
`base0` 高級中等學校校別(含進修部)／**`base3` 高級中等學校校別－按學程別分**／
`basej` 國民中學／`basec` 國民小學／`bases` 國民中小學進修部

**科別資料**：`sdata` 大專校院科系別概況／`students` 大專校院各校科系別學生數／
`graduates` 科系別畢業生／**`base2` 高級中等學校科別資料**

⚠️ 命名沒有規律可循——`students` 是**大專**不是高中職，`bases` 是國中小進修部。
不要從字面猜，一定要查標題對照。

## 四、`base3` 的格式陷阱（實測，十個學年）

要做高中職的**普通科／職業科分流**就是這支。105–114 有，**104 沒有**
（該學年只有 `base0` 與 `base2`）。

| 項目 | 實測差異 |
| --- | --- |
| 格式 | 105–113 有 CSV、111–114 有 XLSX，**114 只有 XLSX** |
| 學生數欄 | **CSV 沒有**，須由逐年級男女＋延修生共 10 欄加總 |
| 學程欄名 | **三種**：`等級名稱`(105)／`學程名稱`(106–110)／`學程(等級)名稱`(111 起) |
| 類別名稱 | 105–106 `進修部(學校)`、`專業群(職業)科`；107 起改短版 |
| 編碼與分隔 | **111 學年是 Big5(cp950)＋Tab**，其餘八年 UTF-8 BOM＋逗號 |
| 欄數 | 105–107 是 22（無縣市欄）、108 起 24 |

作法：編碼與分隔**用嗅探**（依序試 utf-8-sig、cp950；首行有無 Tab 決定分隔），
不要寫死「111 是特例」。類別用**明確對照表**不要模糊比對——
模糊比對會在來源新增類別時把它默默併掉。`附設國中部` 必須排除（那是國中）。

## 五、順帶

`sdata`（大專科系別）**沒有設立別欄位**。要公私立可用校名前綴推
（`國立`／`市立` 開頭為公立），實測 114 學年全體大專生私立占 56.7%。
