寫官方校網頁面時，不要加入「本辦公室將協助尋找適合的申請管道」「有相符資源釋出時主動通知」「本頁定期檢視更新」這類敘述，除非該服務或維護節奏確實存在。使用者的原話是「我們目前沒有這個服務」。

**Why:** 這些句子讀起來像貼心的加值說明，實際上是對外承諾。承諾了卻做不到，比不寫更糟——會有人真的來信等回覆。

**How to apply:** 頁面只寫確定成立的事實（資源內容、資格、期限、窗口）。要蒐集需求或提供諮詢服務，先確認單位真的要做、有人負責，再放上頁面；不要先放表單再想服務怎麼跑。回饋管道只寫信箱（歡迎來信告知），不寫回應時效或更新頻率。相關：[[aio-external-resources-page]]。
