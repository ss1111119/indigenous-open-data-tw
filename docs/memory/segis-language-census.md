## 一、查 SEGIS 有什麼，先看《產品總目錄》

`C:\Users\rsjhu\Downloads\STATCatalog.xlsx`（另有同內容的 `STATCatalog.pdfx.pdf`），
3,044 列，逐列列出名稱／時間／空間範圍／空間統計單元／欄位清單。平台查詢介面可下載。

**不要用關鍵字搜尋找資料集**——同一份統計常有「行政區版」與「統計區版」兩種，
關鍵字只會撈到其中一個。我就是這樣漏掉行政區版，還把「只能到縣市」寫成資料的固有限制
寫進四份文件（已更正）。

看目錄先切兩刀：**空間範圍是否「全國」**（3,044 → 885，其餘是各縣市自行上傳、
定義不一致，多半可忽略）；**是否仍在更新**（885 → 有鄉鎮以下粒度且延續到 112 年後的
只剩 89 筆）。

## 二、怎麼拿到 oCode（開放服務端點的唯一參數）

`data.gov.tw` 的搜尋 API **要 API Key**，`OpenService.asmx` 只有三個取數方法、
沒有目錄方法。可行路徑是走網頁：

1. `https://segis.moi.gov.tw/STATCloud/QueryInterface?keyword=<關鍵字>` → 按「查詢」
2. 點資料名稱 → 開新分頁 `QueryInterfaceView?COL=...&MCOL=...`
3. **那頁的 HTML 原始碼裡有 4 個 `segisws.moi.gov.tw/...?oCode=` 網址**
   （JSON／XML／GeoJSON TWD97／GeoJSON WGS84），curl 抓下來 regex 即可，不必動瀏覽器

行政區系列用 `GetAdminSTDataForOpenCode`，統計區系列用 `GetStatSTDataForOpenCode`。

**2026-08-11 補實測：上面第 1、2 步「非瀏覽器不可」已經證實，不要再找腳本捷徑。**

- 清單查詢是 POST `https://segis.moi.gov.tw/STATCloud/reqcontroller.go`，
  參數 `method` 必須是**加密後的請求碼**（前端 `gs.pageEncrypt`）。明文送
  `method=GetDataSetList` 回 **HTTP 401「認證失敗 : 請求碼不正確」**。
  複製那套加密是未公開且會隨前端改版失效的相依，不值得做。
- `QueryInterfaceView` 的 `COL`／`MCOL` 參數也是加密的，猜不出來。
- `QueryInterface?keyword=<關鍵字>` 用 curl 抓只會拿到空殼（結果靠 AJAX 塞），
  HTML 裡 `oCode` 出現 0 次。
- data.gov.tw 也繞不過去：`/api/front/dataset/search`、
  `/api/v1/rest/datastore/search` 皆 **404**；`/datasets/search?qs=` 回 200 但
  748KB 全是 JS 殼，結果不在 HTML 裡（搜字串 0 命中）。有 API Key 才走得通。

結論：**oCode 是一次性人工取得後寫死成常數**（附取得日期），不要設計成執行期發現。

**⚠️ 更重要的一條：開放服務端點只回傳「最新一期」，拿不到歷年。**
官方文件寫明 `oCode` ＝ 主題代碼＋統計單元代碼＋資料格式，**不含年度**；
`OpenService.asmx` 只有 3 個方法（Admin／Org／Stat），全部只吃 oCode、無時間參數。
實測《行政區大專校院統計》16 個學年（99–114）的產品頁**吐出完全相同的 oCode**，
而該 oCode 回傳的資料 `INFO_TIME` 全是 `114Y`。

歷年要走平台的「連結」按鈕給的下載網址（`reqcontroller.go?method=filedown.
downloadproductfile&code=<DEC_MCOL>&STTIME=<年度>&STUNIT=<單元>&BOUNDARY=…`，
method 是明文、且**帶年度**），但未登入直接抓只會回傳平台首頁 HTML。
**要歷年就得登入**，或改用平台查詢介面逐年手動下載。

規劃任何 SEGIS 專案前先問：**只要最新一期，還是要時間序列？** 兩者難度差很多。

取產品清單的可靠做法（不必解密）：在查詢結果頁的 console 跑
`jQuery('#jTableA').DataTable()`，`rows().data()` 就有每列的 `CNAME`／`DEC_COL`／
`DEC_MCOL`／`STTIME`／`STUNIT_CODE`；`page.len(400).draw()` 可一次取回全部。
（用 `QueryInterface?keyword=<關鍵字>` 進頁面即會自動查詢；但**改 keyword 輸入框再
重繪無效**，選擇器抓不到，換關鍵字要重新導向網址。）

## 五、三個省時間的實測結論

**1. 清單看似分縣市，其實一個入口就是全國。** 平台把同一統計依縣市列成 21–22 筆
「…_鄉鎮市區_○○縣」，看起來要逐縣市抓——**不是**。任一縣市入口的 `oCode` 回傳的
都是全國資料。不要沿用「逐縣市抓 22 個檔」那個模式（那是**統計區版**因平台無彙總檔
才需要的）。

**2. 行政區版的欄位有正式名稱，沒有 `FLD01` 那個坑。** 回應的 `ColumnList` 帶
`COLUMN_NAME` 與中文 `COLUMN_DESC`（如 `NA_STU_CNT` ＝ 原住民學生數）。
但仍要**以名稱取值並先驗存在**，不可用位置——平台新增欄位時位置取值會靜默錯位。

**3. ⚠️ `行政區原住民15歲以上人口十歲年齡組(與性別)與教育程度人口統計`
（112年12月）的縣市歸屬是壞的，2026-08-11 實測，不要用。**

欄位形式為 `A15A24_E2122_CNT`，年齡組 15-24／25-34／35-44／45-54／55-64／65以上，
有村里版，縣市版 22 列、鄉鎮版 368 列，鄉鎮加總與縣市檔**逐縣市完全相符**——
內部一致，但**對外全錯**：

| 縣市 | 原住民總人口(114年12月) | 這份說的 15 歲以上 |
| --- | ---: | ---: |
| 臺南市 | 11,118 | **18,103**（163%，不可能） |
| 雲林縣 | 3,580 | **6,938**（194%，不可能） |
| 花蓮縣 | 94,924 | 60,189（63%，太低） |
| 臺東縣 | 79,340 | 45,117（57%，太低） |

原鄉低估、西部縣市高估，且同一縣市各年齡組同比例偏移——縣市歸屬錯位的特徵。
**內部一致性檢查抓不到這種錯**，只能拿外部數字比對。

**行政區系列其他資料集沒問題**——`行政區原住民人口統計`（縣市／鄉鎮／村里，
到 114年12月、一年四期）實測全國 **629,456**，與已知的 114 年底 62.9 萬完全相符。
壞掉的只有教育程度那一筆。

要原住民成年人口學歷結構，用 **`統計區`版**（走 data.gov.tw dataset 18672，
moe 專案的 `fetch_segis.py`／`build_education.py` 就是這條），它逐縣市對得上外部數字。
代價是只能到縣市——**那是這份資料真正的限制，不是版本選擇**（先前記憶寫反了）。

## 三、109 年語言普查（本次已實測驗證）

主計總處國勢普查處，**不需申請**，全國 368 個鄉鎮市區，欄位含正式的縣市／鄉鎮市區代碼
（不是發布區那種還原不了的內部序號）。同系列三份：**兒時最早學會**／**現在主要及次要
使用**／**父母最常使用**——三份合起來是語言世代斷裂的完整鏈條。

「兒時最早學會語言」鄉鎮市區版 JSON 端點：

```
https://segisws.moi.gov.tw/STATWSSTData/OpenService.asmx/GetAdminSTDataForOpenCode?oCode=BF3B727F423963560BD262FF6FF7387358872164398953095540FAA96511A9BA911B6D4098878E44D8BBECC4B34231B0
```

（把結尾 `911B6D40...` 換成 `14CACBCF325C650BA46DEC5BF5F23516` 得到 XML。）

### ⚠️ 兩個一定會踩的坑

**1. 回傳欄位叫 `FLD01`–`FLD07`，沒有名字，且詮釋資料頁兩處順序互相顛倒。**
用已知鄉鎮反推確認過的正解（＝「資料集摘要」的順序，不是「欄位清單」顯示的順序）：

| 欄位 | 意義 | 驗證依據 |
| --- | --- | --- |
| `FLD01` | 6 歲以上本國籍常住人口 | 全國 21,784,369 |
| `FLD02` | 國語 | 臺北大安 68.1% 最高 |
| `FLD03` | 閩南語 | 彰化鹿港 86.6% |
| `FLD04` | 客語 | 新竹北埔 73.9%、苗栗公館 67.9% |
| `FLD05` | **原住民族語** | 蘭嶼 46.6%、達仁 43.9%；大安 0.0% |
| `FLD06` | 其他語言 | |
| `FLD07` | 不知或無 | |

**2. 值是百分比不是人數**，每列 `FLD02`–`FLD07` 加總恰為 100。
直接 sum 會得到「368」這種無意義的數。**全國或縣市數字必須用 `FLD01` 加權。**

### 已算出的關鍵數字

全國（人口加權）：閩南語 53.21%、國語 40.42%、客語 4.56%、**原住民族語 0.78%**。

兒時最早學會族語比率最高：高雄桃源區 66.0%、屏東霧臺鄉 65.9%、花蓮豐濱鄉 61.0%。
**花蓮秀林鄉只有 26.3%**（59.5% 先學國語）——那是太魯閣族占絕對多數的鄉，
這個落差是整份資料最有話講的地方。

**限制：只有「原住民族語」一個總類，沒有族別**，做不出阿美語專屬分析
（那要走原民會的族語認證資料，見 data.gov.tw dataset 138815、145164，那兩份有族語別
與方言別）。99 年也有語言普查但問法完全不同（問「在家使用」、送相對人次），
**99 與 109 不可直接比**。

## 四、續作建議

放 [[indigenous-constitution-tw]] 而不是 moe 專案——它是族群語言權的證據，
與教育部學生統計無關。且可與該庫既有的 `data/processed/population-by-township.json`
對接，算出「鄉鎮原住民人口占比 vs 兒時學會族語占比」的**傳承落差**。

目錄裡另外兩個對憲政專案有價值的：
`行政區原住民族常住人口之性別及年齡結構普查統計`（99、109 年，縣市／鄉鎮市區）——
**常住口徑，不是戶籍**，兩者差額就是都市原住民的代表性落差；
`行政區6至34歲常住人口之在學情形普查統計`（欄位直接有在學率）。

平埔 0 筆、原住民保留地 0 筆、原住民選舉 0 筆——憲政專案「不取用 SEGIS」的結論不變，
本頁記的是「若要取用語言普查」的前置知識。
