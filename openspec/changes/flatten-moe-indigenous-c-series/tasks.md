## 3. 長表建置

- [x] 3.1 輸出單一長表，欄位為 `學年`／`表號`／`統計別`／`等級別`／`年級`／`族籍別`／`性別`／`設立別`／`學校所在地`／`校碼`／`學校名稱`／`人數` 共 12 欄，不適用的維度欄為空，非空維度由「表號 × 統計別」決定，且 `學年`／`表號`／`統計別`／`人數` 永不為空（Emit a single long table with a mandatory table code column，對應設計決策「長表以可空維度欄搭配必填表號欄」）。驗證：讀入輸出檔後，學年集合恰為 103–114、表號集合恰為 6 個、無 `人數` 為空之列、`人數` 皆為非負整數；`C2-1`／`C2-2` 的畢業生列 `年級` 為空
- [x] 3.1b 長表納入 `校碼` 欄，以字串讀取以免毀損，於 `C2-1`／`C2-2` 必填、其餘表號為空（School codes retain their source form，對應設計決策「長表納入校碼欄」）。驗證：114 學年 `C2-2` 的 `011301` 與 `173E16` 在輸出中保持原形（非 `11301.0`、非 `1.73e+18`）；`縣立中正國小` 的 9 列可由 `校碼` 區分
- [x] 3.2 攤平時以彙總值驗證明細後捨棄彙總，長表只保留最細的明細列與明細欄；驗證不符時報出學年、表號、位置與差值並中止建置（Exclude aggregate rows and aggregate columns，對應設計決策「長表只存明細，彙總值用於驗證後捨棄」）。驗證：對 6 表 × 12 年逐一執行彙總檢查全數通過；輸出中不含任何總計列或總計欄
- [x] 3.3 指標欄中無法讀為非負整數的儲存格視為阻斷性錯誤，報出學年、表號、位置與原始儲存格內容並中止（Values that cannot be read as counts are surfaced as errors）。驗證：以人工置入非數值標記的暫存副本執行建置，確認報錯內容包含原始儲存格文字且未產出長表
- [x] 3.4 指標欄的 `-` 讀為整數 0，其餘無法讀為非負整數的內容仍為阻斷性錯誤（Dash cells are read as zero，對應設計決策「遮蔽符號 `-` 一律讀為 0」）。驗證：114 學年 `C1-2` 新北市與臺北市的畢業生列，明細加總在 `-` 讀為 0 後與原檔總計欄零誤差相符；12 學年全部 269 個 `-` 皆轉為 0 且未觸發錯誤
- [x] 3.5 行政區名一律用「臺」並切除英文尾綴，`學校所在地` 只存中文名（Administrative division names are normalized，對應設計決策「縣市名統一用「臺」並去除英文尾綴」）。驗證：輸出中 `學校所在地` 不含 `台` 字與任何拉丁字母；`臺北市 Taipei City` 正規化為 `臺北市`
